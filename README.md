# 👥 HR Workforce Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **HR Workforce Analytics Dashboard** developed in Power BI to analyze employee demographics, hiring activity, attrition, job satisfaction, work-life balance, and compensation trends.
The dashboard provides a consolidated view of key workforce metrics and helps transform HR data into clear, actionable business insights.

## 📊 Dashboard Preview

![Dashboard Preview](Image/HR_Workforce_Analytics_Dashboard.png)

## 🎯 Project Objectives

The main objectives of this project are to:

- 👥 Monitor overall workforce size and active employees
- 📈 Analyze hiring patterns across different periods
- 📉 Track employee terminations and attrition
- 🎓 Understand workforce distribution by education
- ⭐ Evaluate employee job satisfaction
- ⚖️ Analyze employee work-life balance
- 💰 Explore salary and compensation trends
- 🔍 Enable interactive analysis through dynamic filters

## 📊 Dashboard Analysis

### 👥 Employee Overview

The dashboard provides an overview of the current workforce across key dimensions, including:

- 👤 Gender
- 🎓 Education
- ⭐ Job Satisfaction
- ⚖️ Work-Life Balance

### 📈 Hiring Analysis

Quarterly new-hire analysis helps identify changes in recruitment activity throughout the year and compare hiring levels across quarters.

### 📉 Attrition Analysis

Quarterly and monthly termination trends provide visibility into employee exits and changes in workforce levels.

### 💰 Compensation Analysis

Salary trends are analyzed using:

- 📅 Monthly average salary
- 🏢 Years at the company
- 💼 Total working years

These visualizations help explore how employee compensation varies with tenure and overall professional experience.

## 🔍 Interactive Filters

The dashboard includes interactive slicers for:

- 🏢 Department
- 📉 Attrition
- 💼 Employment Type
- 👤 Gender

These filters allow users to explore workforce metrics across different employee segments.
